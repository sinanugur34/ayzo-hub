# Phase 7.4 — Preview canonical RPC transfer source, Sonic and Mantle

## Root-cause evidence
Phase 7.3 exact-source Preview acceptance: Sonic's Etherscan `getLogs` returned HTTP 200 with `INVALID_LOGINDEX` on indexed rows and the attempted reconciliation still returned `UPSTREAM_ERROR`; Mantle's indexed first page also intermittently returned `UPSTREAM_ERROR`. Neither network passed that particular 2-page live acceptance. Earlier Mantle succeeded, so provider behavior is inconsistent. Indexed logs cannot be silently treated as canonical evidence when logIndex or completeness is uncertain.

## Scope and mechanics
For the **GoldRush exit Preview canary only**, select the public-chain canonical `eth_getLogs` result for both supported networks (Sonic `rpc.soniclabs.com`, Mantle `rpc.mantle.xyz`) in the existing 2,048-block signed cursor window. The indexer is still used for `eth_blockNumber` to set the initial bounded head, but **the indexer is not trusted for transfer event rows**. One RPC query per direction, exact token address and Transfer event with indexed wallet topic. The existing strict `parseLog` and `logs` checks require actual transaction hash, block, event topics, value and `logIndex`; all records must be parseable. Self-transfers are deduplicated by transaction hash plus logIndex. No partial pages, no guessing: >=50 logs in either direction, too-large response, malformed JSON-RPC, missing identity or timeout fail closed. The older `etherscan-log` cursor format, wallet/chain/token binding and expiry remain unchanged. Real per-call telemetry provider labels are `sonic-rpc` and `mantle-rpc`; the orchestration adapter currently retains providerId `etherscan` for compatibility and MUST be renamed/clarified before Production certification.

## Security and limitations
This is NOT a certified full historical indexer: each call covers one 2,048-block slice only. Explicit continuation may return an empty page plus a non-null cursor; consumers must traverse it. Public RPC endpoints may impose block-range/rate limits, do not guarantee archive retention, and do not commit to service levels. Each analysis may perform 1 Etherscan head request + 2 public RPC requests per page; cost/rate limits and Free/Pro/Advanced 20/60/200 parity remain unproven. Read-only preview and no sensitive wallet secrets. Before merging: run identical real-witness Sonic/Mantle first+second-page, cursor and fail-closed tests; verify RPC chain identity and stress-test dense wallet pagination. Until that is complete, PR #151 stays Draft and Production remains GoldRush-backed.
